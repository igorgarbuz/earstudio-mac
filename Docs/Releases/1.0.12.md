EarStudio Companion 1.0.12 updates the product artwork and release documentation.

### Changes

- Replace the product image with an original owner photograph and improve its layout on the device settings screen.
- Update shared support text and documentation for the iPhone app, now named ES100 Control. The Mac app remains EarStudio Companion.
- Publish support and privacy information for the App Store submission.

### Installation and validation

Download the DMG and drag EarStudio Companion into Applications. Requires macOS 14 or newer; includes Apple Silicon and Intel binaries. A SHA-256 checksum is provided beside the DMG.

The release workflow runs shared-core and native macOS tests, verifies Developer ID signatures and both architectures, and checks uploaded asset digests before publishing.

**Signed, not notarized:** this release has not been submitted to Apple's notary service. macOS may still require Open Anyway in System Settings → Privacy & Security.
