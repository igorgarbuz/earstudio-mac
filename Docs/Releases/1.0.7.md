EarStudio Companion 1.0.7 remembers device authorization without Keychain access and makes installation and hardware documentation easier to find.

### Changes

- Store device confirmation locally in Application Support, with access restricted to your macOS user. Unchanged keys are not rewritten, other devices' keys are preserved, and damaged files are not overwritten.
- Report failures to save or forget a device confirmation accurately.
- Add a prominent download link, the original ES100 product photo, project background, and direct links to two PDF manuals and six technical references in the README.

### Upgrade and install

Quit any older version, download **EarStudio-Companion-1.0.7-macOS-universal.dmg**, open it, and drag **EarStudio Companion** into **Applications**. Requires **macOS 14 or newer**, on **Apple Silicon or Intel**.

On your first connection after upgrading from 1.0.6, briefly press the ES100 power button if prompted. The app does not read, migrate or delete the previous Keychain entry; subsequent connections use the new local store.

This community release is **ad-hoc signed and not notarized by Apple**. If macOS blocks it, attempt to open the app, then use **System Settings → Privacy & Security → Open Anyway** for this intentionally downloaded copy. Keep Gatekeeper enabled.

To verify the download, save the accompanying checksum file beside the DMG and run:

```sh
shasum -a 256 -c EarStudio-Companion-1.0.7-macOS-universal.dmg.sha256
```

### Validation and limitations

- All 28 Swift Package core tests and 74 native Xcode tests passed, including device-key persistence, file permissions, unchanged writes, damaged storage, reconnect authorization and save/forget failures.
- The release package includes verified Apple Silicon and Intel binaries and a SHA-256 checksum.
- No new physical-device validation is claimed for this release. Broader ES100 MK2 and older-firmware testing remains ongoing. Firmware flashing and factory reset are not included.

Report problems through [GitHub Issues](https://github.com/igorgarbuz/earstudio-mac/issues), including app/macOS/device firmware versions and sanitized diagnostics.
