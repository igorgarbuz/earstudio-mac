EarStudio Companion 1.0.10 makes the active Bluetooth audio source easier to identify and clarifies how to pair an ES100 or MK2 with a Mac.

### Changes

- Show both Bluetooth source slots beside the analog volume controls, with a checkmark and green highlight on the active slot. The tooltip explains that the other source may still be connected and that playback on the source device determines the active input.
- Show explicit status for USB audio, idle input, and a disconnected device, with an accessibility label for the current input.
- Use consistent EarStudio capitalization in the sidebar.
- Clarify that the device must be paired with this Mac in macOS Bluetooth settings, including when USB carries audio. Explain that app authorization is separate from Bluetooth pairing.
- Include contribution guidance, issue and pull request templates, security reporting instructions, and macOS CI added since 1.0.9.
- Report version **1.0.10 (13)**.

### Validation and limitations

Publication requires both complete test suites, a fresh universal archive and DMG, signing and architecture verification, and matching uploaded asset digests. The repository also requires passing core and native macOS CI checks before merging the release changes.

The source indicators display the input reported by the device; they do not identify source devices or provide input switching controls. No additional physical ES100/MK2 validation is claimed for this release. The app remains ad-hoc signed and not notarized by Apple; see the README for first-launch instructions.
