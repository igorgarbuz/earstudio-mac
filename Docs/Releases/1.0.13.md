ES100 Control 1.0.13 renames the macOS app formerly known as EarStudio Companion and makes Reset to flat preserve your EQ processing options.

### Changes

- Rename the app, window, About information, diagnostics headers, installer, and release assets to ES100 Control. EarStudio ES100 and ES100 MK2 remain the supported hardware.
- Reset to flat now resets only preamp and band gains. Band width, headroom, analog compensation, and whether EQ is enabled remain unchanged.
- Update installation and support documentation for the new name. Existing preferences, saved presets, and device authorization keep their existing storage locations and identifiers.

### Installation and upgrade

Download **ES100-Control-1.0.13-macOS-universal.dmg**, open it, and drag **ES100 Control.app** into Applications. Requires macOS 14 or newer; includes Apple Silicon and Intel binaries.

When upgrading from EarStudio Companion, quit the old app first. After installing ES100 Control, remove **EarStudio Companion.app** from Applications to avoid keeping two copies. The new filename does not automatically replace the old app.

A SHA-256 checksum accompanies the DMG. Verify it from the download directory:

```sh
shasum -a 256 -c ES100-Control-1.0.13-macOS-universal.dmg.sha256
```

### Validation and signing

The release workflow runs shared-core and native macOS tests, verifies Developer ID signatures and both architectures, and checks uploaded asset digests before publishing. Automated tests cover preservation of EQ processing settings when resetting to flat; these changes have not received additional physical-device verification.

**Signed, not notarized:** the release workflow signs the app and DMG with Developer ID but does not submit them to Apple's notary service. macOS may require Open Anyway in System Settings → Privacy & Security; see the README's first-launch instructions.
