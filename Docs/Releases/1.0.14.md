ES100 Control 1.0.14 fixes preset recognition on macOS. This is a patch release for compatible behavior fixes; no data migration is required.

### Changes

- Derive the displayed preset name from current device EQ settings, including after reconnecting or restarting the app once settings have been read.
- Show checkmarks for matching saved and factory presets in the macOS preset menu. Identical presets can all match; differently named saved matches display “Matching presets.” Unmatched settings display “Custom.”
- Compare gains at the ES100's 0.1 dB precision so imported decimal values remain recognized after device readback. Saved presets also compare supported processing options; factory presets compare only preamp and band gains.
- Update matching indicators after manual edits and device readback, including when a device rejects an edit.

### Installation and upgrade

Requires macOS 14 or newer. When the release is published, install **ES100-Control-1.0.14-macOS-universal.dmg** by quitting the app and replacing **ES100 Control.app** in Applications. Existing preferences, saved presets, and device authorization are preserved.

When upgrading from the older EarStudio Companion name, remove **EarStudio Companion.app** after installing ES100 Control to avoid keeping two copies.

### Validation and release status

PR validation recorded 61 passing shared-package tests and 53 passing macOS tests, including preset matching after restart/readback, duplicate matches, device precision, older firmware, and rejected-edit recovery. These checks use simulated transports; physical ES100 preset matching remains unverified.

These notes prepare the release. The 1.0.14 distribution has not yet been packaged, signed, or notarized; those checks remain required before publication.
