First public release of EarStudio Companion, an independent native macOS controller for the EarStudio ES100 and ES100 MK2.

### Changes

- Native SwiftUI interface with equalizer, presets, output, DAC, input, ambient/call, battery and device controls, plus offline help and diagnostics.
- Corrected all ten EQ band IDs and slider dragging; device readback preserves later queued edits.
- All 34 exposed setting commands confirm the actual firmware value through readback, including when a write acknowledgement is absent. Corrected packet groups, packed fields, firmware gates and legacy USB-format handling.
- Connection cleanup waits for channel close. Explicit **Reconnect Bluetooth** recovery is available after a control-channel opening failure; it briefly interrupts Bluetooth audio.
- A process-wide startup lock brings the existing app forward when another copy is launched. A separate control-channel lease also prevents overlapping device sessions.
- MIT license, original vector artwork, public build documentation, and a reusable release script.

### Install

Download **EarStudio-Companion-1.0.6-macOS-universal.dmg**, open it, and drag the app into Applications. Quit any older version first. Requires **macOS 14 or newer**; supports **Apple Silicon and Intel**. No audio driver is needed.

This early community release is **ad-hoc signed and not notarized by Apple**. If macOS blocks it, attempt to open the app, then use **System Settings → Privacy & Security → Open Anyway** for this intentionally downloaded copy. Keep Gatekeeper enabled.

The accompanying `.dmg.sha256` file verifies download integrity. In the download folder, run:

```sh
shasum -a 256 -c EarStudio-Companion-1.0.6-macOS-universal.dmg.sha256
```

### Validation and limitations

- 64 native Xcode tests and 28 Swift Package core tests passed. Tests cover protocol encoding, every exposed control against simulated firmware, neighboring fields, optional acknowledgements, rejected/truncated replies, firmware boundaries, and connection/process lifecycle.
- Physical ES100 firmware **2.0.2** testing confirmed authentication and all five settings-readback groups. Manual Bluetooth disconnect/reconnect restored a stalled control channel after relaunch.
- The new recovery button and every real-device setting have not all been physically exercised. MK2 and older firmware need broader hardware validation. Firmware flashing and factory reset are not implemented.
- The EQ has fixed band centers and two Q choices, as in the Android app; it is not an arbitrary parametric EQ.

Please report reproducible problems with the app/macOS/firmware versions and sanitized diagnostics through [GitHub Issues](https://github.com/igorgarbuz/earstudio-mac/issues).
