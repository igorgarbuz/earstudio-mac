EarStudio Companion 1.0.11 introduces Developer ID signing for the macOS app and disk image.

### Changes

- Sign the universal app and DMG with the maintainer’s Developer ID Application certificate, with a secure timestamp and hardened runtime for the app.
- Share protocol, session and interface components between the Mac and iPhone apps.
- Include version, build number and source revision in app diagnostics.
- Fix macOS test-script compatibility with the system Bash.
- Update iPhone documentation following successful maintainer hardware testing and add App Store archive tooling and privacy information. This release distributes only the macOS app.

### Installation and validation

Download the DMG, drag EarStudio Companion into Applications, and pair your ES100/MK2 with this Mac before connecting. Requires macOS 14 or newer; includes Apple Silicon and Intel binaries. A SHA-256 checksum is provided beside the DMG.

The release workflow runs shared-core and native macOS tests, verifies the Developer ID signature and both architectures, and checks uploaded asset digests before publishing.

**Signed, not notarized:** this release has not been submitted to Apple’s notary service. macOS may still require Open Anyway in System Settings → Privacy & Security. No additional macOS hardware coverage is claimed.
